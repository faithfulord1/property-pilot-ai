# PropertyPilot AI - Product Specification Archive

This repository preserves the original PropertyPilot AI product specification.

## Canonical runnable project

The maintained application is here:

**https://github.com/faithfulord1/PropertyPilot-AI-**

That repository contains the working client, API, deterministic deal analysis, deployment configuration, security hardening, CI checks and governed read-only MCP tools.

## What belongs here

- Original product specification and design material
- Historical requirements that explain how the product evolved
- Reference material for future roadmap decisions

This repository is intentionally not the deployable application. Keeping the specification separate prevents visitors from mistaking a document-only repository for the working product.

## Portfolio scenario

A reviewer who wants to understand the original product thinking can read the specification here. A recruiter, collaborator or technical reviewer who wants to inspect or run the application should use the canonical repository above.
